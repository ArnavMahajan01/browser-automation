# 09 — Gitignore Agent Folders

**Date:** Sep 6, 2026 — 7:15 PM

## What changed

### `.gitignore`
Added three entries under a new `# agent tooling` section:
- `.agents/` — Cursor agent skills (local AI tooling, not app code)
- `.claude/` — Claude agent skills (local AI tooling, not app code)
- `skills-lock.json` — Agent skills lockfile

## Why

These folders contain AI agent configuration files generated by Cursor/Claude. They are machine-specific, not part of the application, and should never be pushed to version control or deployed. They have no effect on the Next.js build — Next.js only bundles files that are explicitly imported in app code.
